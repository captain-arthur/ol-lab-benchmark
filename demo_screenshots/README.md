# 📸 Demo Screenshots

스크린샷용 데모 파일들이 저장된 폴더입니다.

## 📁 파일 목록

### 1. Input (위키 전문)
- **파일**: `demo_wiki_input.html`
- **내용**: 머신러닝에 대한 위키 전문 문서
- **용도**: Input 스크린샷용

### 2. Query (데이터 수집 요청)
- **파일**: `demo_data_collection_query.html`
- **내용**: "머신러닝 정의 데이터 수집해줘" 요청
- **용도**: Query 스크린샷용

### 3. Output (구조화된 결과)
- **파일**: `demo_structured_result.html`
- **내용**: 요청에 대한 정리된 답변
- **용도**: Output 스크린샷용

### 4. 요약
- **파일**: `demo_simple_summary.md`
- **내용**: 전체 플로우 요약 및 설명

## 🎯 사용 방법

1. 각 HTML 파일을 브라우저에서 열기
2. 스크린샷 캡처
3. Input → Query → Output 순서로 정리

## 📸 스크린샷 캡처 방법

```bash
# 브라우저에서 열기
open demo_wiki_input.html
open demo_data_collection_query.html  
open demo_structured_result.html
```

## 🔄 데모 플로우

**Input (위키 전문)** → **Query (데이터 수집 요청)** → **Output (구조화된 결과)**

- 위키: 머신러닝 전문 내용
- 쿼리: "머신러닝 정의 데이터 수집해줘"
- 결과: 머신러닝 정의가 구조화된 문장들로 정리
