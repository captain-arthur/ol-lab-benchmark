
# 📊 Simple Data Collection Demo

## Input: Wikipedia Document
```
Machine learning (ML) is a subset of artificial intelligence (AI) that focuses on algorithms and statistical models. 
    It enables computer systems to automatically learn and improve from experience without being explicitly programmed.
    
    Machine learning algorithms build mathematical models based on training data to make predictions or decisions.
    The field is closely related to computational statistics, which focuses on making predictions using computers.
    
    There are three main types of machine learning:
    1. Supervised learning: Learning with labeled training data
    2. Unsupervised learning: Finding patterns in data without labels
    3. Reinforcement learning: Learning through interaction with environment
    
    Applications include computer vision, speech recognition, email filtering, and medical diagnosis.
    Popular algorithms include linear regression, decision trees, neural networks, and support vector machines.
    
    Machine learning is used in many applications, such as in medicine, email filtering, speech recognition, 
    and computer vision, where it is difficult or unfeasible to develop conventional algorithms to perform the needed tasks.
```

## Query: Data Collection Request
**"머신러닝 정의 데이터 수집해줘"**

## Output: Structured Result

    머신러닝 정의:
    
    • 머신러닝(ML)은 인공지능(AI)의 하위 분야로, 알고리즘과 통계 모델에 중점을 둡니다.
    • 컴퓨터 시스템이 명시적으로 프로그래밍되지 않고도 경험으로부터 자동으로 학습하고 개선할 수 있게 합니다.
    • 머신러닝 알고리즘은 훈련 데이터를 기반으로 수학적 모델을 구축하여 예측이나 결정을 내립니다.
    • 이 분야는 컴퓨터를 사용한 예측에 중점을 둔 계산 통계와 밀접한 관련이 있습니다.
    

---
**Example Flow:**
- Wiki: "오늘의 날씨는 맑다. 내일은 비가 온다."
- Query: "내일 날씨 데이터 수집해줘"  
- Result: "내일은 비가 온다."
